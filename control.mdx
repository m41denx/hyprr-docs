## Консоль & Управление сервером

Вкладка консоли позволяет управлять сервером в реальном времени:

- ввод команд
- история выполненных команд
- отображение онлайна и статуса сервера(запускается/остановлен)
- адрес для подключения к серверу
- статистика сервера
- выбор оптимизации и версии Java

Основные действия доступны в один клик:

- запуск
- остановка
- перезапуск
- экстренный сброс (<u>возможна потеря данных</u>)

## Файловый менеджер и Бекапы

Встроенный файловый менеджер позволяет полностью управлять файлами через браузер:

- редактор файлов как VS Code (а для настроек популярных файлов есть простой редактор)
- навигация по папкам
- загрузка и скачивание файлов
- создание и удаление файлов
- **распаковка архивов (.zip)** прямо в панели
- подсказки популярных файлов или папок

**Ограничения загрузки:**

- через сайт можно загружать файлы до **1 GB**
- для больших файлов рекомендуется использовать SFTP

### Бэкапы

В панели доступны резервные копии сервера:

- создание бэкапов вручную
- восстановление в один клик
- возможность **заблокировать/разблокировать бэкап от удаления**

### SFTP доступ

Для удобной работы с файлами вы можете подключиться к серверу через SFTP:

- все данные для подключения (хост, порт, логин) доступны в панели
- полный доступ к файловой системе сервера
- стабильная загрузка больших файлов

Рекомендуется использовать SFTP (например, FileZilla или WinSCP) для загрузки сборок, больших архивов.
