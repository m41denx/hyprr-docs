### SFTP доступ

Для удобной работы с файлами вы можете подключиться к серверу через SFTP:

- все данные для подключения (хост, порт, логин) доступны в панели
- полный доступ к файловой системе сервера
- стабильная загрузка больших файлов

Рекомендуется использовать SFTP (например, FileZilla или WinSCP) для загрузки сборок, больших архивов.

## Сеть и подключение

Сетевые настройки в HYPRR позволяют легко подключаться к серверу, настраивать домены и использовать внутреннюю сеть проекта.

### IP и порты

Каждому серверу выделяется:

- уникальный порт с IP
- 🔌 до **5 портов на сервер**

Порты можно использовать для:

- дополнительных игровых сервисов
- прокси
- веб-интерфейсов (Dynmap и т.д.)

### привязка домена

Вы можете подключить свой домен или использовать наш к серверу, чтобы игроки заходили без указания порта.

Например:

```text
play.yourdomain.com
```

### Внутренняя сеть проекта

Все ресурсы внутри одного проекта могут общаться между собой через внутреннюю сеть HYPRR.

- высокая скорость соединения
- отсутствие внешнего интернета
- используется для серверов, БД и приложений

### Подключение к серверу

Для подключения к серверу используйте:

- IP-адрес и порт (из панели)
- или домен, если он настроен

Пример подключения:

```text
IP:PORT
```

## Modrinth

HYPRR поддерживает интеграцию с Modrinth - это позволяет устанавливать плагины, моды и датапаки прямо из панели управления.

### Установка в один клик

Вы можете устанавливать контент без ручной загрузки файлов:

- плагины (Paper / Purpur и др.)
- моды (Fabric / Forge / NeoForge)
- датапаки

Достаточно выбрать нужный элемент и нажать Установить - всё остальное сделает система.

### Автоопределение совместимости

HYPRR автоматически проверяет:

- версию Minecraft
- выбранное ядро
- тип загрузчика (Fabric / Forge и т.д.)

И показывает только совместимые варианты.

<Note>
  Это снижает шанс ошибок и избавляет от ручного подбора версий.
</Note>

### Управление установленным

После установки вы можете:

- удалять моды и плагины
- обновлять их
- быстро находить нужные элементы

## Настройки сервера

В этом разделе доступны расширенные настройки сервера, позволяющие гибко управлять его поведением и производительностью.

### Смена ядра и версии

Вы можете в любой момент изменить:

- ядро сервера (Paper, Purpur, Forge и др.)
- версию Minecraft

### Изменение тарифа и железа

Вы можете масштабировать сервер без потери данных:

- увеличение или уменьшение тарифа
- смена поколения нод (Gen1 / Gen2 / Gen3)

<Info>
  При изменении тарифа пересчёт происходит автоматически - оплачивается только разница.
</Info>

### Команда запуска (Startup Command) & Переменные окружения

Позволяет полностью контролировать запуск сервера:

- указание Java аргументов
- выбор основного jar-файла
- кастомные параметры запуска

Вы можете задавать переменные окружения для сервера:

- конфигурация плагинов
- параметры модов
- настройки приложений

### Настройки Java(В консоли)

Доступна гибкая настройка Java-окружения:

- выбор версии Java
- настройка GC (Garbage Collector)
- оптимизационные флаги
