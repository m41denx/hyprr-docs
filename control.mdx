## Настройки сервера

В этом разделе доступны расширенные настройки сервера, позволяющие гибко управлять его поведением и производительностью.

### Смена ядра и версии

Вы можете в любой момент изменить:

- ядро сервера (Paper, Purpur, Forge и др.)
- версию Minecraft

### Изменение тарифа и железа

Вы можете масштабировать сервер без потери данных:

- увеличение или уменьшение тарифа
- смена поколения нод (Gen1 / Gen2 / Gen3)

<Info>
  При изменении тарифа пересчёт происходит автоматически - оплачивается только разница.
</Info>

### Команда запуска (Startup Command) & Переменные окружения

Позволяет полностью контролировать запуск сервера:

- указание Java аргументов
- выбор основного jar-файла
- кастомные параметры запуска

Вы можете задавать переменные окружения для сервера:

- конфигурация плагинов
- параметры модов
- настройки приложений

### Настройки Java(В консоли)

Доступна гибкая настройка Java-окружения:

- выбор версии Java
- настройка GC (Garbage Collector)
- оптимизационные флаги
