Встроенный файловый менеджер HYPRR позволяет полностью управлять файлами сервера прямо из браузера - без необходимости устанавливать дополнительные программы.

## Основные возможности

<Steps>
  <Step title="Навигация по папкам" icon="arrow-down-short-wide">
    Удобный просмотр структуры файлов и быстрый переход между директориями
  </Step>
  <Step title="Редактор файлов (как VS Code)" icon="code">
    Встроенный редактор с подсветкой синтаксиса (Monaco Editor)\
    Подходит для редактирования конфигов, кода и любых текстовых файлов
  </Step>
  <Step title="Упрощённый редактор" icon="gear-complex-code">
    Для популярных файлов (например, `.properties`, `.yml`) доступен более простой интерфейс
  </Step>
  <Step title="Загрузка и скачивание файлов" icon="download">
    Загружайте файлы с компьютера или скачивайте их обратно в один клик
  </Step>
  <Step title="Создание и удаление" icon="file-waveform">
    Создавайте новые файлы и папки или удаляйте ненужные
  </Step>
  <Step title="Работа с архивами" icon="box-archive">
    Распаковывайте и запаковывайте архивы прямо в панели без дополнительных инструментов
  </Step>
  <Step title="Подсказки структуры" icon="file-circle-info">
    Быстрый доступ к популярным папкам и файлам сервера
  </Step>
</Steps>

**Ограничения загрузки:**

- через сайт можно загружать файлы до **1 GB**

<Tip>
  Для больших файлов и сборок рекомендуется использовать SFTP
</Tip>
