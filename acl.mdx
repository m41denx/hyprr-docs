HYPRR позволяет работать над проектом в команде: вы можете добавлять участников и гибко настраивать их права доступа.

## Администраторы проекта

Вы можете добавить других пользователей в проект:

- пригласить по аккаунту HYPRR
- выдать права администратора или ограниченный доступ
- управлять участниками в любое время

Администраторы получают доступ к управлению ресурсами в рамках выданных прав.

## Настройка ACL прав

ACL (Access Control List) позволяет точно определить, что может делать пользователь.

Доступные типы прав:

- **Чтение** — просмотр информации
- **Изменение** — изменение настроек
- **Запись** — полный доступ (включая управление сервером)

Вы можете:

- настраивать права для каждого участника
- ограничивать доступ к критическим функциям
- создавать безопасную командную работу

## Оверрайды для ресурсов

Оверрайды позволяют задавать права **отдельно для конкретных ресурсов**:

- серверов
- приложений
- баз данных

Например:

- дать доступ только к одному серверу
- запретить доступ к базе данных
- ограничить действия внутри проекта

<Tip>
  Это удобно для разделения ролей (разработчик, модератор и т.д.)
</Tip>

## Удаление доступа

Вы можете в любой момент:

- удалить пользователя из проекта
- изменить его права
- ограничить доступ к отдельным ресурсам

После удаления:

- пользователь теряет доступ ко всем ресурсам проекта
- данные проекта остаются без изменений

## Важно

- права применяются сразу после изменения
- администраторы с полным доступом могут управлять всеми ресурсами
- будьте осторожны при выдаче прав на запись
