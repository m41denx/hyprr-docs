Для удобной и стабильной работы с файлами вы можете подключиться к приложению через SFTP.\
Это особенно полезно для загрузки больших файлов и управления приложением вне браузера.

## Данные для подключения

Все необходимые данные доступны в панели управления:

- **Хост (адрес приложенния)**
- **Порт**
- **Логин**
- **Пароль** (или поменяйте в настройках пароль при использовании Google/Disocrd)

## Возможности SFTP

- Полный доступ к файловой системе приложенния
- Загрузка файлов без ограничений браузера
- Скачивание любых файлов
- Массовое управление файлами и папками
- Стабильная передача данных даже при больших объёмах

## Рекомендуемые клиенты

Для подключения можно использовать любые SFTP-клиенты, например:

- **FileZilla**
- **WinSCP**

Они позволяют удобно управлять файлами через графический интерфейс.

### Особенности доступа

- доступ ограничен файлами конкретного приложенния
- системные файлы хостинга недоступны
- права доступа соответствуют настройкам приложенния
