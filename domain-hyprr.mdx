В HYPRR вы можете использовать встроенные домены без необходимости покупать свой. Это самый простой способ быстро запустить сервер или приложение.

## Что это даёт

- не нужно покупать домен
- моментальная настройка
- подключение без DNS
- удобно для тестов и небольших проектов

## Домены для Minecraft серверов

Для игровых серверов доступны специальные домены:

```text
***.play.hyprr.space
***.playingfor.fun
***.zeroiq.club
```

## Пример

```text
myserver.play.hyprr.space
funserver.playingfor.fun
easyserver.zeroiq.club
```

## Как использовать

При создании сервера:

1. Введите желаемое имя
2. Выберите домен
3. Готово — можно подключаться

## Домены для приложений и БД

Для приложений, сайтов и баз данных используется:

```text
***.zeroiq.club
```

### Пример

```text
api.zeroiq.club
myapp.zeroiq.club
```

### Возможности

- доступ к веб-приложениям
- автоматический SSL (HTTPS)
- интеграция с HYPRR Router

## Важно

- домен должен быть уникальным
- после удаления ресурса домен освобождается
- некоторые имена могут быть заняты
