Создать приложение в HYPRR можно за пару минут — достаточно выбрать источник кода, настроить окружение и нажать **Создать**

## Что такое приложение

Приложение — это любой сервис, который вы запускаете в облаке:

- сайт (Next.js, Nuxt, React)
- бот (Discord, Telegram)
- API или backend
- любые сервисы на Node.js и других языках

## Источник кода

При создании приложения нужно выбрать, откуда загружать код:

### Git (рекомендуется)

Подходит для автоматического деплоя.

Укажите:

- URL репозитория
- ветку (по умолчанию `main`)
- (опционально) логин и токен для приватных репозиториев

Вы можете включить:

- автоматический `git pull` при запуске

<Tip>
  Используйте Git для удобного обновления приложения без ручной загрузки файлов.
</Tip>

### Файлы

- загрузка проекта вручную
- подходит для простых приложений
- можно использовать ZIP или SFTP

## Настройки окружения

Вы можете настроить, как будет запускаться приложение.

### Node.js

- выбор менеджера пакетов:
  - `npm`
  - `yarn`
  - `pnpm` (рекомендуется)

Пример:

```bash
pnpm --frozen-lockfile
```

### Команда запуска

Укажите команду из `package.json`:

```bash
start
```

Это будет выполнено как:

```bash
npm run start
```

## Тариф и железо

Приложения работают на **Gen1 нодах**

Тариф определяет:

- CPU (ядра)
- RAM (оперативная память)
- диск

## Дополнительное место на диске

Если стандартного объёма недостаточно, вы можете:

- увеличить диск при создании
- или добавить его позже

## Что входит

- стабильная работа приложений
- доступ по домену
- интеграция с другими сервисами проекта

## Как выбрать тариф

- небольшие боты и тесты \> минимальный тариф
- сайты и API \> средний тариф
- нагруженные проекты \> увеличенный тариф

### Важно

- приложение должно корректно запускаться локально
- команда запуска должна существовать
- для приватных репозиториев нужен токен
