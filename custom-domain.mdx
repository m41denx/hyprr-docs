Вы можете подключить собственный домен к серверу, чтобы игроки заходили без IP и порта.

## Зачем нужен домен

Без домена подключение выглядит так:

```text
luxor-1.eu-central.hyprr.space:15300
```

С доменом:

```text
play.mysite.com
```

- проще запомнить
- выглядит профессионально
- удобно для игроков

## Как подключить домен

Вам нужно создать **2 DNS записи** у вашего доменного провайдера:

1.  CNAME (обязательная)
2.  SRV (необязательная, но рекомендуется)

## CNAME запись (обязательно)

Это основная настройка, которая “привязывает” домен к вашему серверу.

### Что это значит

CNAME говорит:

“если кто-то заходит на ваш домен — отправь его на сервер HYPRR”

### Как заполнить

Создайте запись:

```text
Тип: CNAME  
Имя: play  
Значение: ваш-сервер.hyprr.space  
```

### Важно

- `play` — это поддомен (можно любой: mc, server и т.д.)

- `ваш-сервер.hyprr.space` — берётся из панели HYPRR(**БЕЗ ПОРТА**)

<Warning>
  **На CloudFlare обязательно должен быть выключен proxy(оранжевое облако)**
</Warning>

### Пример

```text
play.mysite.com → luxor-1.eu-central.hyprr.space
```

## SRV запись (чтобы убрать порт)

По умолчанию игрок подключается так:

```text
play.mysite.com:23575
```

SRV запись позволяет убрать `:15300`

### Как заполнить

```text
Тип: SRV  
Имя: _minecraft._tcp.play  
Приоритет: 0  
Вес: 5  
Порт: 15300
Цель: play.mysite.com
```

### Объяснение простыми словами

- `_minecraft` \> для игры Minecraft
- `_tcp` \> тип соединения
- `play` \> ваш поддомен
- `25565` \> порт сервера
- `play.mysite.com` \> ваш домен

## Как это работает

1. Игрок вводит:

```text
play.mysite.com
```

2. SRV запись говорит: “используй порт 25565”
3. CNAME говорит: “сервер находится на HYPRR”
4. Происходит подключение 

## Проверка DNS

После добавления записей:

1. Подождите 5–15 минут (иногда до часа)
2. Перейдите в панель HYPRR(В сервере\>)
3. Нажмите:

```text
Проверить DNS записи домена
```

Вы увидите:

-  СNAME / A запись
- SRV запись

## Возможные проблемы

- DNS ещё не обновился
- ошибка в имени записи
- неправильно указан домен
- забыли SRV или CNAME
