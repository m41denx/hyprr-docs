Каждый сервер в HYPRR имеет собственные сетевые настройки для подключения и взаимодействия с другими сервисами.

## Порты сервера

- каждому серверу выделяется до **5 портов**
- основной порт используется для подключения игроков
- дополнительные порты можно использовать для:
  - веб-карт (Dynmap, BlueMap)
  - API и плагинов
  - других сервисов

## IP-адрес

- серверу автоматически назначается IP-адрес
- подключение осуществляется по формату:
  ```text
  IP:порт
  ```

---

## 🔗 Внутренняя сеть проекта

Все ресурсы внутри одного проекта объединены внутренней сетью:

- серверы могут подключаться друг к другу напрямую
- доступ к базам данных без внешнего интернета
- минимальная задержка\\

<Tip>
  Это удобно для настройки прокси (Velocity / BungeeCord) и микросервисной архитектуры
</Tip>
