## Что такое проект и зачем он нужен

**Проекты на HYPRR** — это папки, объединяющие ваши сервера и предоставляющие некоторые дополнительные функции, о которых мы поговорим позже.

Вообще проектом может быть как большой набор серверов (Лобби, Velocity/Bungeecord, сервер для анархии и пара серверов для миниигр), так и буквально один маленький сервер для друзей.

В каждом проекте общая сеть для соединения между серверами, общие администраторы проекта, общие базы данных и есть глобальные бэкапы, не привязанные к серверу.

**Все ресурсы внутри проекта:**

- Связаны внутренней сетью
- Управляются вместе
- Могут взаимодействовать друг с другом

<Tip>
  Сервер Minecraft может подключаться к базе данных и API внутри одного проекта без внешнего интернета.
</Tip>

## Регионы

**Регион** — он и есть регион. Вы могли заметить в ваших ссылках на сервера слова `ru-west` и `eu-central` — собственно Западная Россия и Центральная Европа

Внутри региона работает одна и так же DDoS защита, а между нодами максимальный пинг достигает всего 2-5мс. Если не уверены, что выбрать — берите Москву, мы постоянно докупаем туда ноды, там лучшая DDoS защита и доступно самое мощное железо.

### Доступные регионы:

- **ru-west (Москва)**
  - Лучший выбор для игроков из России и СНГ
  - Максимальная защита от DDoS
- **eu-central (Европа)**
  - Подходит для европейской аудитории
  - Стабильный доступ из ЕС
  - В принципе тут тоже очень хорошая защита, причем с тонкой очисткой

<Tip>
  Рекомендуется выбирать регион ближе к вашей основной аудитории.
</Tip>

## Лимиты

- Максимум **10 проектов на один аккаунт**
- Внутри проекта количество серверов не ограничено

## Управление проектами

После создания проекта вы можете:

- Переименовать проект
- Добавить администраторов и настроить права доступа (ACL)
- Управлять всеми ресурсами в одном месте
