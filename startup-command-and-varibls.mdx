Подходит для продвинутых пользователей.

## Startup Command (команда запуска)

Startup Command - это команда, с которой запускается сервер.

В большинстве случаев её **не нужно менять**, так как она уже настроена системой.

Но при необходимости вы можете:

- изменить `.jar` файл сервера
- добавить кастомные параметры запуска
- настроить поведение сервера

<Warning>
  Неправильное изменение команды запуска может привести к тому, что сервер не запустится.
</Warning>

## Java флаги

Вы можете указать дополнительные параметры для Java:

Примеры:

- оптимизация производительности
- включение экспериментальных модулей
- настройка поведения JVM

Пример флагов:

```text
-Dterminal.jline=false
-Dterminal.ansi=true
--add-modules=jdk.incubator.vector
```
