## Возможности консоли

- **Ввод команд**\
  Выполняйте команды сервера прямо из панели
- **История команд**\
  Просматривайте ранее выполненные команды и повторяйте их при необходимости
- **Статус сервера**\
  Отображение текущего состояния:
  - запускается
  - работает
  - остановлен
- **Онлайн игроков**\
  Быстрая информация о количестве игроков на сервере
- **Адрес подключения**\
  IP и порт для подключения к серверу
- **Статистика сервера**\
  Основные показатели нагрузки (CPU, RAM и др.)
- **Настройки Java и GC**\
  Возможность выбрать версию Java и оптимизацию сборщика мусора (Garbage Collector)
