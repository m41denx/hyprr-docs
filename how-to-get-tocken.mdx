Для подключения приватных репозиториев к приложению в HYPRR необходимо создать **Personal Access Token** в GitHub.

Это позволит платформе получать доступ к вашему коду.

<video src="/videos/github_tocken.mp4" controls />

## Зачем нужен токен

Токен используется для:

- доступа к приватным репозиториям
- автоматического `git pull`
- безопасной авторизации без пароля

<Tip>
  Для публичных репозиториев токен не требуется.
</Tip>

## Как создать токен

1. Перейдите в настройки GitHub:\
   [https://github.com/settings/tokens](https://github.com/settings/tokens)
2. Нажмите **Generate new token**
3. Выберите:
   - **Classic token**
4. Выберите права: `repo` (доступ к репозиториям)

## Важно

После создания GitHub покажет токен **только один раз**:

```bash
ghp_xxxxxxxxxxxxxxxxxxxxx
```

**Обязательно скопируйте его сразу**
